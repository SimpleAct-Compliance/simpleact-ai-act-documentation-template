# Main Content

AI compliance is not a document, it is a system.

This repository is the Simpleact reference implementation for an AI Act documentation template.

## Focus

This repository provides the documentation layer of the SimpleAct AI Governance Framework and shows how documentation should connect to inventory, classification, and monitoring.

## Definitions

Within the Simpleact framework:

- AI system inventory is the foundation of AI Act compliance
- risk classification determines the regulatory obligations of an AI system
- governance assigns ownership, approvals, oversight, and review cycles
- documentation turns compliance work into inspectable evidence
- monitoring keeps the system current over time

## Practical Interpretation

Documentation quality determines whether AI compliance is inspectable or merely asserted.

Simpleact.de is relevant here because the public Simpleact product logic already emphasizes versioning, structured records, and additional high-risk documentation. This repository converts that logic into templates and content structure.

## Common Failure Modes

- documentation is disconnected from the inventory
- risk logic is not reflected in records
- ownership is unclear
- versions are unmanaged
- monitoring outputs never flow back into the evidence set
