# Checklist

AI compliance is not a document, it is a system.

Within the Simpleact framework, this checklist tests whether the documentation layer is strong enough to support real AI compliance review.

## Inventory

- AI systems, tools, and providers are listed
- owners and purposes are defined
- deployment context is documented
- documentation records link back to inventory entries

## Classification

- prohibited practice screening exists
- high-risk relevance is assessed
- assumptions and reasoning are recorded
- documentation reflects the classification outcome and rationale

## Governance

- roles and approvals are assigned
- review cadence exists
- human oversight is defined
- documents show ownership, approval, and version responsibility

## Documentation

- evidence-ready records exist
- templates are used consistently
- exports can support audits or internal review
- documentation structure is repeatable across systems
- key records can be updated over time

## Monitoring and Reporting

- incidents and changes are tracked
- reassessment triggers are defined
- reporting outputs can be generated
- documentation changes when systems, providers, or use cases change
