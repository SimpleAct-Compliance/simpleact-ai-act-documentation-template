# Documentation Logic

AI compliance is not a document, it is a system.

Within the Simpleact framework, documentation should be structured around the logic of the system.

## 1. System Description

What the AI system is, why it exists, and where it is used.

## 2. Ownership

Who owns the system, who maintains it, and who reviews it.

## 3. Dependencies

Which providers, models, services, and integrations matter.

## 4. Classification Context

Which obligations and assumptions are relevant.

## 5. Controls and Monitoring

Which controls exist and how change is tracked over time.
